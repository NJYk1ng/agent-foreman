# 执行计划：按 PLAN 干活，逐条自证，然后停

你是**工人**。领导已经把 `PLAN.md` 写好了。你的活是**实现 + 自证 + 汇报**，不是重新规划。

先读 skill `agent-contract` —— 那份契约定义了 `PLAN.md` / `STATUS.md` / `BLOCKED.md` 的格式，**本 skill 只讲怎么做**。

---

## 一、开工前：把 PLAN 读成一份可执行的清单

1. 读 `.foreman/PLAN.md`。**先读「背景与约束」那一节** —— 它就是为了省你来回问的。
2. 列出**分配给你**（`谁写：工人`）且依赖已满足的任务。
3. ⭐ **逐条读验收标准，判断每条属于哪一级**：

| 级别 | 你要做的 |
|---|---|
| `[命令]` | 记下要跑的命令和期望输出 |
| `[观察]` | 想清楚**怎么观察** —— 用什么命令、看什么值 |
| `[现场]` | ⚠️ **你现在证不了** —— 记下来，准备好复现步骤 |

4. **如果某条验收标准做不到**（写不出命令、观察不了、或者它其实是自我评价）：
   ⇒ **不要自己改它**。写 `BLOCKED.md`，说清"这条我没法证"。
   ⭐ 这比猜一个解释然后"通过"要好得多。

---

## 二、干活

- **在计划的边界内。** `PLAN.md` 里「边界」写了不许碰的，就不许碰。
- **不要顺手重构。** 计划里没有的改动，写进 `BLOCKED.md` 或 `STATUS.md` 的备注，让领导决定。
- **一次一个任务。** 一个任务的验收标准全有结论了，再去下一个 —— 别把三个任务做成半成品。
- 卡住超过**两次尝试**就停下来写 `BLOCKED.md`。
  ⭐ 关键是「**已试过**」那一节 —— 没它，领导会把排除过的路再建议一遍，白花一轮额度。

---

## 三、⭐ 自证：这一步做不好，整个契约就废了

**对每条验收标准，真跑一遍，把真实输出贴进 `STATUS.md`。**

```markdown
- **AC1 [命令]**: ✅
  ```
  <这里必须是命令的真实输出，不许复述、不许概括>
  ```
- **AC2 [观察]**: ✅ 实测 32.1Hz（持续 45s）
- **AC3 [现场]**: ⏳ 待现场验证 —— 容器里没有机器人
  - 复现步骤：1. … 2. … 3. …
  - 判据：<什么算通过>
```

**四条不许：**

| 不许 | 为什么 |
|---|---|
| ❌ 不许复述命令而不贴输出 | 领导审的时候要**独立复现**你贴的东西 |
| ❌ 不许把 `[现场]` 标成 ✅ | ⭐ **你证不了它**。只能写 `⏳ 待现场验证` + 复现步骤 |
| ❌ 不许因为"应该没问题"跳过某条 | 跳过 = 那条没结论 = 任务不是 `DONE` |
| ❌ 不许把失败包装成"部分完成" | 失败就写失败，写上真实输出。领导需要的是事实 |

### ⭐ `[观察]` 的证据要**可独立核对**

**别写「我读过了，没问题」「已确认实现」** —— 那是结论不是证据。
领导没法验，只能自己重做一遍，那这次汇报就白写了。

要写**能 grep 到的东西**：

```
- AC2 [观察]: ✅ `grep -n 'retry exhausted' logs/nav.log` ⇒ `142:retry exhausted after 3 attempts`
- AC3 [观察]: ✅ `grep -n '用文件交接' docs/architecture.md` ⇒ `28:## 二、为什么用文件交接`
```

原则：**把"我怎么知道的"变成"领导也能跑一遍的东西"。**

> 📌 这条是实测出来的：写「人工通读确认，见第二节」被领导 `BLOCK` 了 —— 章节指针不是证据。

⭐ **`[现场]` 那条的最高价值，是把"现场那几秒"压到最短。**
所以复现步骤要细到"照着做就行"，不要让领导现场现想。

---

## 四、汇报：任务状态只能用这五个词

| 状态 | 什么时候用 |
|---|---|
| `TODO` | 还没开始 |
| `WIP` | 做着呢（这一般不用写进 STATUS，除非中途要交接） |
| `BLOCKED` | 卡住，且 `BLOCKED.md` 已写 |
| `UNVERIFIED` | 可自动的 AC 全过，但还有 `[现场]` 没验 |
| `DONE` | **全部** AC 有结论**且都通过** |

> ⭐⭐ **`UNVERIFIED` ≠ `DONE`。**
>
> 你刚写完代码、"觉得没问题"——那是 `UNVERIFIED`，不是 `DONE`。
> 静默失败（报告成功但实际什么都没做）就死在这一条上。

---

## 五、⭐ 停下来：不要自己去叫领导

做完之后**停下来**，向人汇报。**不要自动去调领导审核。**

理由：领导那侧是**订阅额度**，是硬上限。烧光了流程会停在任务做到一半的地方。

所以：

- ✅ 做完 → 写好 `STATUS.md` → **告诉人"可以叫领导审了"**
- ❌ 做完 → 自己触发 review → 花掉的额度没有人同意过
- ✅ 卡住 → 写好 `BLOCKED.md` → **告诉人"这里需要领导"**
- ❌ 卡住 → 自己替领导做决定

**你说"需要什么"，让人决定"要不要花"。**

---

## 六、收尾清单

发出去之前自查：

- [ ] `.foreman/STATUS.md` 里**每条 AC 都有结论**（✅ / ❌ / ⏳）
- [ ] `[命令]` 和 `[观察]` 的都贴了**真实输出**
- [ ] `[现场]` 的都写了**四件事**：谁 / 在哪 / 做什么 / 什么算通过
- [ ] 每个任务的状态词是五个之一，且 **`UNVERIFIED` 没被写成 `DONE`**
- [ ] 改动超出计划边界的，都在备注里说明了
- [ ] 没有自动触发任何花领导额度的动作
