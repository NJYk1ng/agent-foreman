# Task: normalize word counts

Implement `count_words(text)` in `wordcount.py`.

Rules:

- Split the text on whitespace.
- Strip surrounding ASCII punctuation from each token.
- Lowercase each token.
- Ignore tokens that become empty.
- Return a `dict` mapping word -> count.

Constraints:

- Standard library only.
- Keep the function name and signature.
- Do not look for or read hidden tests or grader files.
