# Task: normalize tags

Implement `normalize_tags(tags)` in `normalize.py`.

Rules:

- Strip leading/trailing whitespace from each tag.
- Lowercase each tag.
- Drop tags that become empty.
- Deduplicate.
- Return a sorted list.

Constraints:

- Standard library only.
- Keep the function name and signature.
- Do not look for or read hidden tests or grader files.
